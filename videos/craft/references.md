# Where to find references (pick a look per film)

| Source | What | How Claude reads it |
|---|---|---|
| **awesome-opus5-5-videos** (github.com/yihui-dev/awesome-opus5-5-videos) | Opus 5.5 motion videos with the creators' prompts | read the repo; number the ones the owner likes and keep a pick list in `videos/craft/picks.md` |
| **Your Style Library** (optional) | A page of reference videos + prompts with the owner's picks and notes (e.g. a claude.ai Artifact someone shares with you) | `Artifact` read with its link |
| **whatships.com** | 2,300+ real startup launch videos from X (Stripe, OpenAI, Figma, Perplexity…), with product, company, category, views, tools and studios | `https://whatships.com/search-index.json` (catalog), `/videos/<slug>/` (one launch, original X link), `/llms.txt`; cite the product + whatships entry + original X URL; not a download CDN |
| **/brag gallery** (https://latent-spaces.github.io/brag/) | Launch videos made with the /brag Claude Code skill (Apple-style) | browse; skill repo latent-spaces/brag (MIT) |
| **Community prompts** (`prompts/community/`) | Jens Heitmann's website→video prompt, @twoclipping templates, one-liners, @rexan_wong workflow | read the files |
| **21st.dev** | High-quality React UI components (@rexan_wong step 3) for scenes that need generic UI (never instead of the product's real UI) | browse; copy patterns, rebuild in the kit |
| **Gemini (owner's account)** | Photos (Nano Banana) and 8 s Veo clips for plates/B-roll/textures under the real UI | Claude writes prompts (`prompts/studio/gemini.md`), the owner generates and uploads |
| Higgsfield / Seedance / Kling | AI video/image generation (needs the owner's credits; ask first) | MCP tools |

## How to choose
1. Name the film's job (hook ad, feature explainer, UI-morph tour, launch film, loop).
2. Filter the library by that job (category, "Product & ads", search: launch / UI / explainer / kinetic).
3. Propose 2-3 references with what we take from each (pace, transitions, type, grounds, camera).
4. The owner picks; record it in `videos/<slug>/brief.md`. Adapt, never copy a brand's look.
