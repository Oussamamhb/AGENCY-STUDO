# Prompt library

Ready-to-use prompts from the "How to build a motion design studio with Opus 5.5" course
(@0xMovez). Copy one, fill in the [BRACKETS], paste it to Claude in this project.

| File | Use it for | Size |
|---|---|---|
| `showreel.md` | Testing the setup (one-liner + 4 variants) | L1–L2 |
| `product-reel.md` | A launch / promo video for a real product | L2 |
| `reference.md` | Copying the *style* of a video or frame you love | step before any build |
| `ui-morph.md` | "One shape, never cut" UI product film (XML spec) | L3 |
| `director-brief.md` | Flagship films, long runs, multi-session productions | L4 |
| `critique-pass.txt` | The self-review loop Claude runs before showing you anything | every video |

Effort: medium for small fixes and re-renders, **xhigh** for new films, **max** when the
first 3 seconds have to carry a launch (`/model` → effort).

A one-liner tests the engine. It never tests the idea, because it doesn't contain one.
Hundreds of people used the same showreel sentence, so those reels all rhyme ("brief
contagion"). Use it to test, then move on to a real brief.
